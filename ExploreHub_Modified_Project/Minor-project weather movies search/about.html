ABOUT THE PROJECT

Simple tools. Useful discoveries.

NovaView brings weather information and movie discovery together in one beginner-friendly web project.

Project objectives

This minor project demonstrates how HTML, CSS and modern JavaScript can work together to build interactive websites that consume public APIs.

01

API integration

Request and display live data from external services.

02

Async JavaScript

Use fetch, async/await, promises and error handling.

03

Responsive design

Create pages that adapt to desktop and mobile screens.
